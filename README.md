# Terminal Snake Game

A classic retro Snake game built completely in Python using the native `curses` terminal interface.

## Features
- Pure terminal interface using Python standard libraries.
- Score tracking and interactive snake growth.
- Game-over collision detection for walls and self-intersection.

## Prerequisites
- Python 3.x
- Standard terminal (Linux / macOS / WSL on Windows). Windows users outside WSL may require `windows-curses` (`pip install windows-curses`).

## How to Run
```bash
python snake.py
```

## Controls
- **Arrow Keys**: Control snake movement direction.
- **Ctrl + C**: Exit game.
